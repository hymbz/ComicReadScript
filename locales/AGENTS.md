# locales 翻译要求

本项目默认语言为中文（`zh.json` 为原文）。翻译时请遵循以下原则。

## 核心：简洁优先

中文天然比英文等语言更简洁，非中文文案在 UI 中更容易超出显示框宽度而导致换行。虽然项目会在非中文语言下加宽显示框，但加宽幅度有限（过多会影响美观）。因此翻译应**尽量简短**。

为压缩篇幅，允许：

- 用缩写代替全拼，例如用 `LR` 代替 `left/right`；
- 用简短但略生僻的词，例如用 `abreast` 代替 `side-by-side`；
- 在必要时让用户稍微思考一下才能理解，仍可接受。

## 优先级

按重要性从高到低：

1. **准确**：首先必须保证用户能看懂意思。
2. **简洁**：在可懂的前提下尽量简短（见上）。
3. **地道**：避免让用户感到不自然，但仅作为最后的润色，不能与简洁冲突。

## 权衡规则

- 若简洁与准确冲突，**以准确优先**：某个翻译如果可能让用户看不懂，应选择更易读的表达，哪怕更长。
- 反之，只要能看懂，即使表达稍显生僻、需要思考一下，也优先选择更短的写法。
